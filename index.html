Как вставить в Figma Sites

Прямые ссылки ниже — публичные адреса файлов на GitHub Pages. Их можно вставлять в блок Embed как URL, а можно собрать iframe вручную.

  1. Insert → Embeds. Выберите блок URL и вставьте прямую ссылку на файл — Figma подтянет страницу сама.
  2. Если блок URL не сработал, выберите вариант HTML и вставьте iframe-код ниже.
  3. Задайте блоку пропорции 16:9, чтобы фон не обрезался.
<iframe src="https://arelman.github.io/green-wave/green-wave.html"
        width="100%" height="100%"
        style="border:0;display:block;aspect-ratio:16/9"
        loading="lazy" title="Green wave"></iframe>
<iframe src="https://arelman.github.io/green-wave/green-smoke.html"
        width="100%" height="100%"
        style="border:0;display:block;aspect-ratio:16/9"
        loading="lazy" title="Green smoke"></iframe>
